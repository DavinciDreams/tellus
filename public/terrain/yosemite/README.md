# Yosemite Terrain

Static Tellus chunk bake from USGS 3DEP public-domain elevation data.

Source: https://prd-tnm.s3.amazonaws.com/StagedProducts/Elevation/13/TIFF/current/n38w120/USGS_13_n38w120.tif

BBox: -119.72, 37.69, -119.48, 37.8

Chunks: 20 x 12

Elevation range: 996.11m to 3024.67m; reference 1212.3m.
