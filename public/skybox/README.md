# Skybox Assets

Place the extracted `free_-_skybox_in_the_cloud/` folder in this directory to
use it as the Tellus skybox. If that model is not available, Tellus also tries
the bundled Tellus cubemap skyboxes, `free_-_skybox_in_the_cloud.glb`,
`skybox_skydays_3.glb`, and then the bundled basic skybox.

Bundled skyboxes load from:

```text
/skybox/free_-_skybox_in_the_cloud/scene.gltf
/skybox/tellus-storm-ocean/scene.gltf
/skybox/tellus-desert-sunset/scene.gltf
/skybox/tellus-alien-rings/scene.gltf
/skybox/tellus-aurora-sky/scene.gltf
/skybox/tellus-starry-night/scene.gltf
/skybox/tellus-blue-clouds/scene.gltf
/skybox/free_-_skybox_in_the_cloud.glb
/skybox/skybox_skydays_3.glb
/skybox/free_-_skybox_basic_sky.glb
```
